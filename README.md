# Dr. Fred Nyamitago Monari, PhD

### Computational Mathematician | Applied Statistician | Data Scientist | AI Evaluation

Lecturer and Research Fellow at **Kisii University, Kenya**, with a PhD in Applied Statistics and extensive experience in mathematical modelling, statistical computing, quantitative research and data science.

My work focuses on computational mathematics, statistical inference, numerical optimization, scientific computing, statistical modelling and the evaluation of computational solutions.

I am particularly interested in developing reproducible computational tasks, validating mathematical and statistical methods, identifying errors in AI-generated solutions, and establishing objective technical evaluation criteria.

## Featured Computational Projects

### 1. AI Statistical Evaluation Benchmark

A reproducible Python benchmark demonstrating statistical reasoning, logistic regression, reference solutions, error detection and objective evaluation rubrics.

**Key competencies:** Statistical modelling, odds ratios, confidence intervals, statistical interpretation and automated testing.

[View Statistical Evaluation Project](https://github.com/MonariF/AI-Statistical-Evaluation-Benchmark)

### 2. AI Numerical Optimization Benchmark

A computational mathematics benchmark covering constrained optimization, SciPy, numerical convergence, feasibility verification and Karush-Kuhn-Tucker (KKT) conditions.

**Key competencies:** Mathematical optimization, numerical methods, constraint verification and optimization diagnostics.

[View Numerical Optimization Project](https://github.com/MonariF/AI-Numerical-Optimization-Benchmark)

### 3. AI Probability and Statistical Inference Benchmark

A reproducible Python benchmark covering binomial probability, exact hypothesis testing, confidence intervals, Monte Carlo simulation and statistical reasoning.

**Key competencies:** Probability distributions, exact inference, simulation and hypothesis testing.

[View Probability and Statistical Inference Project](https://github.com/MonariF/AI-Probability-Statistical-Inference-Benchmark)

### 4. AI Statistical Model Validation Benchmark

A Python benchmark evaluating statistical learning, logistic regression, stratified cross-validation, predictive performance and data leakage.

**Key competencies:** ROC AUC, Brier score, log loss, bootstrap confidence intervals and model validation.

[View Statistical Model Validation Project](https://github.com/MonariF/AI-Statistical-Model-Validation-Benchmark)

### 5. AI Numerical Methods and Linear Algebra Benchmark

A computational mathematics benchmark covering numerical linear algebra, matrix conditioning, Cholesky factorization, nonlinear root finding and numerical integration.

**Key competencies:** Numerical stability, residual analysis, forward error, Simpson's rule and scientific computing.

[View Numerical Methods Project](https://github.com/MonariF/AI-Numerical-Methods-Linear-Algebra-Benchmark)
